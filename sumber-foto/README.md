## Struktur penamaan

```
KUMPULAN FOTO ALBUM/
├── <tahun hijriah> H/            1444 H … 1448 H
│   └── <n>.<BULAN>/              mis. 5.OKTOBER
│       └── <tgl> <BULAN> <tahun> <PAKET> [BUS n]
│                                 mis. 4 OKT 2026 PLATINUM, 23 MARET 2026 SILVER BUS 2
├── HAJI 2025/FOTO ALBUM HAJJ 1446
└── HAJI 2026/FOTO ALBUM HAJJ 1447 H
```

- Satu folder rombongan = satu keberangkatan (tanggal + paket).
- Paket yang muncul: BRONZE, SILVER (SV), PLATINUM (PLAT), PREMIUM (PREM),
  12HARI (12H), plus program wisata: TURKI (TK), AQSO, MESIR, DUBAI, BURSA,
  CAPPADOCIA (CAPPA), QATAR (QR), OMAN, I'TIKAF, MK, MED/JED (rute Madinah/Jeddah).
- Album 2023 (1444 H) mencantumkan nama ustadz pembimbing di nama folder,
  mis. `MAY 18-05-2023 SV (UST.TAHIR)`.

## Catatan teknis

- Sebagian besar file adalah foto WhatsApp (`WhatsApp Image <tanggal> at <jam>.jpeg`),
  ±100–250 KB, lebar ±1600 px — cukup untuk foto isi artikel, agak kecil untuk
  hero image layar lebar.
- Ada arsip `.rar` besar (mis. `23 SEPT 2026 12H.rar`, ±190 MB) yang perlu
  diekstrak dulu sebelum bisa dipakai.
- Nama file tidak menjelaskan isi/lokasi foto; konteks acara diambil dari nama folder.

## Pedoman pemakaian untuk artikel

1. **Satu artikel per rombongan** — gunakan foto dari folder rombongan yang
   sama dengan yang diberitakan.
2. **Jangan mengarang fakta.** Jumlah jamaah, hotel, nama muthawwif/ustadz,
   kota asal, dan jadwal yang tidak terlihat di foto atau nama folder ditandai
   `[perlu dikonfirmasi]` di draft.
3. **Privasi jamaah** — utamakan foto rombongan/jarak jauh; hindari close-up
   perorangan kecuali jamaah sudah setuju dipublikasikan. Jangan menyebut nama
   jamaah tanpa izin.
4. **Simpan sebagai draft** di WordPress (news.elharamainwisata.com, blog ID
   `257737206`) untuk dicek tim sebelum terbit.
5. Isi alt text foto dengan deskripsi singkat + nama rombongan, mis.
   `Jamaah umroh Elharamain paket Platinum 4 Oktober 2026 di Masjid Nabawi`.
